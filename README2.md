# 천안시 출산·육아 지원정책 | 웹 프레젠테이션

원본 PPT 10장의 순서, 정책 문구, 색상 및 가족 이미지에 맞춰 구성한 반응형 웹 프레젠테이션입니다.

## 실행

- `index.html`을 크롬, 엣지, 사파리 등에서 엽니다.
- `3.html`은 기존 개인 포트폴리오의 3번 메뉴에서 연결할 때 사용합니다.
- 두 HTML 파일 모두 같은 `assets/` 폴더를 사용하므로 **폴더 구조를 그대로 유지**하세요.
- 슬라이드 이동: 상단 메뉴, 하단 좌·우 버튼, 키보드 ←/→, 터치 스와이프, 휠 스크롤.
- 우측 상단 `▦` 전체 목차 / `⛶` 전체화면.

## GitHub Pages 게시

1. GitHub에서 새 저장소를 생성합니다 (예: `cheonan-family-policy`).
2. 이 ZIP의 압축을 풀고 **index.html, 3.html, assets 폴더를 모두 저장소 최상위 폴더에 업로드**합니다.
3. 저장소에서 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**를 선택합니다.
4. 게시된 웹 주소를 Padlet에 '링크'로 등록합니다. HTML 파일 자체를 첨부하면 Padlet이 실행하지 않고 파일로 취급할 수 있습니다.
5. 기존 포트폴리오에 연결할 때는 3.html 및 assets 폴더를 같은 경로에 배치하고 `href="3.html"`로 연결합니다.

## 주의

- 가족 GIF는 웹 페이지에서 직접 로드하므로 브라우저에서는 재생되지만, 일부 플랫폼의 링크 썸네일은 정지 이미지로 표시될 수 있습니다.
- 정부·천안시 지원사업의 금액과 수급 자격은 제공 PPT에 기재된 내용을 그대로 반영했습니다. 대외 게시 전에 담당 부서 최신 고시 확인이 필요합니다.
- 인터넷 연결이나 서버 측 프로세스는 필요 없으나, 신청 사이트 이동 링크는 인터넷 연결이 있어야 합니다.
